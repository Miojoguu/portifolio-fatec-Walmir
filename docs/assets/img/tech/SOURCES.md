# Icon sources

## WhatsApp project additions

- `redis.svg`, `axios.svg`: Devicon, MIT.
- `whatsapp.svg`, `render.svg`, `replit.svg`: Simple Icons, CC0. WhatsApp represents the Meta integration used in the project.

## Animus additions

- `flutter.svg`, `dart.svg`, `fastapi.svg`, `sqlalchemy.svg`, `docker.svg`, `googlecloud.svg`, `pulumi.svg`, `firebase.svg`: Devicon, MIT. Cloud Run and Firebase Auth use the corresponding platform symbols.
- `pydantic.svg`, `googlegemini.svg`, `qdrant.svg`: Simple Icons, CC0.
- `component.svg`, `route.svg`, `bot.svg`, `layers.svg`, `binary.svg`, `workflow.svg`: Lucide, ISC/MIT; generic illustrations for Riverpod, GoRouter, Agno, RAG, embeddings, and Inngest, respectively. Dio uses the generic network illustration in `rest-api.svg`. These illustrations are not brand logos.

- `express.svg`, `tailwindcss.svg`, `mongodb.svg`, `postgresql.svg`: [Devicon](https://github.com/devicons/devicon), MIT; see `LICENSE-devicon.txt`.
- `esp32.svg` (Espressif symbol), `mqtt.svg`: [Simple Icons](https://github.com/simple-icons/simple-icons), CC0; see `LICENSE-simple-icons.txt`. Brand colors applied locally.
- `rest-api.svg`: generic network symbol from [Lucide](https://github.com/lucide-icons/lucide/blob/main/icons/network.svg), ISC/MIT; see `LICENSE-lucide.txt`. Stroke color applied locally. REST does not have a single official logo.
